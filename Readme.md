# 🚚 Delivery Route Optimization using AI

## Problem
Delivery routes are inefficient in real-world logistics.

## Solution
We built an AI environment where an agent learns optimal delivery paths using Reinforcement Learning.

## Features
- Custom OpenEnv environment
- Q-learning agent
- Visualization grid
- Multiple delivery points

## How to Run
python train.py

## Impact
Can be used in:
- Amazon logistics
- Food delivery apps
